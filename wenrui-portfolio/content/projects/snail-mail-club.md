## Overview

Snail Mail Club is a game concept centered on a craft table. The player would choose paper, cut and fold it, decorate a letter and assemble their own snail mail.

This project is in concept and planning. Unity, C# and Blender are intended production tools; no finished gameplay or shipped build is presented here.

## My role

I defined the core activity, tool interactions, desk layout and a manageable solo-development scope.

## Challenges

### Problem

Paper crafting offers many interactions, but reproducing every physical possibility would quickly become too large for one developer.

### Why

Cutting, folding, decorating, storage and a rotating shop each affect the same tabletop workflow.

### Solution

The concept keeps the craft table central, limits simultaneous objects and treats the shop and upgrades as support for the main creative loop.

### Result

The current result is a scoped design direction, ready for prototype validation. There are no sales or player metrics yet.

## Process

The intended path is concept, a small interaction prototype, gameplay testing, art and polish. This is a plan, not a claim that each stage is complete.

## Outcome

The next milestone is a playable desk interaction. Gameplay captures and a silent preview will replace the visual placeholder once that prototype exists.
