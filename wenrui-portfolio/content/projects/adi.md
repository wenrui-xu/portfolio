## Overview

ADI brings tasks, recurring routines, visual sequences and calendar views together in a native Android app. It supports personal use and adapted modes for autistic users, users with ADHD and tutors.

I developed ADI as my final-year Multimedia Engineering project and defended it in October 2026.

## My role

I worked across interaction flows, visual design, Kotlin implementation, local data and user testing. The app uses Jetpack Compose for its interface and Room for local storage.

## Challenges

### Problem

The same task can need very different levels of detail depending on the person using the app.

### Why

A dense task screen can make planning harder. Tutor controls and routines also need to remain understandable when switching modes.

### Solution

I built adapted task views, pictogram-led sequences and tutor controls, then tested task creation, voice controls, recurring behavior and back navigation with users.

### Result

The sessions identified concrete issues with voice affordances, repeated subtasks, routine completion and navigation. Those findings informed subsequent iterations; no quantitative outcome is claimed here.

## Process

Research and interface decisions informed the Android implementation. AI-assisted interpretation and offline speech were explored as supporting tools, followed by user sessions and changes based on observed problems.

Feedback from user testing gave the next iteration a clear list of problems to fix. Final screenshots, a public source link and measured usability results can be added when available.
